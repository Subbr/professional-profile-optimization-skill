# Revisão, consistência e adaptação para vaga

## Coerência entre documentos

LinkedIn, CV e Cover Letter devem contar a mesma história — não precisam ser cópias:

- **LinkedIn** — Mais amplo e pesquisável.
- **CV** — Mais direcionado à vaga e conciso.
- **Cover Letter** — Mais contextual e específico.
- **Entrevista** — Mais narrativa e aprofundada.

Os fatos precisam permanecer consistentes entre todos.

## Adaptação para vaga

Quando houver uma vaga específica:

1. Identificar cargo.
2. Identificar senioridade.
3. Extrair requisitos.
4. Separar must-have de nice-to-have.
5. Identificar palavras-chave.
6. Identificar responsabilidades.
7. Identificar domínio.
8. Comparar com o perfil.
9. Destacar experiências relevantes.
10. Reduzir conteúdo irrelevante.
11. Adaptar headline/resumo quando apropriado.
12. Adaptar CV.
13. Criar Cover Letter específica.

Nunca inserir uma competência apenas porque aparece na vaga — só se sustentada pela experiência real (ver gap analysis em `diagnostico-e-descoberta.md`).

## Sistema de revisão

Avaliar o perfil nestas dimensões:

| Dimensão | Pergunta |
|---|---|
| Posicionamento | Está claro quem é o profissional? |
| Senioridade | O texto demonstra o nível real? |
| Relevância | Está alinhado ao cargo desejado? |
| Keywords | Usa termos relevantes do mercado? |
| Evidências | Existem resultados concretos? |
| Escopo | A escala está clara? |
| Narrativa | A carreira faz sentido? |
| Clareza | Um recrutador entende rapidamente? |
| Naturalidade | Parece escrito por uma pessoa? |
| Consistência | LinkedIn/CV/cover letter contam a mesma história? |
| Internacionalização | O inglês é natural e profissional? |
| ATS | O conteúdo é semanticamente compatível com vagas-alvo? |

Não transformar essa avaliação em uma "nota" quando a finalidade for orientar decisão profissional. O objetivo é identificar pontos fortes, lacunas e ações concretas.

## O que não fazer

Não:

- Inventar métricas, ferramentas, liderança ou resultados.
- Inflar cargos.
- Traduzir literalmente títulos estranhos.
- Preencher o perfil com buzzwords.
- Repetir a mesma informação em todas as seções.
- Colocar toda a carreira com o mesmo nível de detalhe.
- Transformar atividades em resultados sem evidência.
- Usar inglês excessivamente sofisticado.
- Escrever um About genérico.
- Copiar a descrição da vaga.
- Usar keywords desconectadas da experiência.
- Esconder uma transição de carreira que pode ser um diferencial.
- Presumir que ausência de informação significa ausência de experiência.
